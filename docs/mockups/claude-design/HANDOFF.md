# Handoff: Кастомный лаунчер BMW X5 E53 (Android 13, XTRONS / Microntek)

## Overview
Полноэкранный Android-лаунчер для головного устройства XTRONS (BMW X5 E53). Заменяет заводской домашний экран. Стиль — premium automotive в духе iDrive 2016: тёмный графит, дозированный янтарь приборной подсветки, 3D-карусель плиток. Реализация — **Jetpack Compose**.

## About the Design Files
Файл `E53 Launcher.dc.html` в этом пакете — **дизайн-референс, созданный в HTML**. Это прототип, показывающий внешний вид и поведение, а НЕ production-код. Задача — **воссоздать эти макеты в Jetpack Compose**, используя токены и спецификации из этого README. HTML открывается в браузере: на одном холсте лежат все итерации; актуальные экраны перечислены ниже.

## Fidelity
**High-fidelity.** Цвета, размеры, типографика и отступы финальные — воспроизводить точно. Все размеры в этом документе указаны в **dp** (экран 1280×720 px @ 240 dpi → 853×480 dp, density 1.5; в HTML-макете 1 dp = 1.5 px).

## Утверждённые экраны (что реализуем)
Смотреть в HTML по якорям-бейджам:
- **3a — Музыка (финальная версия)**: конверт + выезжающая пластинка. Версии 1b и 2b — устаревшие итерации, не реализовывать.
- **2a — Home**: карусель с крупными иконками (версия 1a устарела).
- **2c — Телефон** (набор номера)
- **2d — Bluetooth**
- **1c — Приложения** (сетка)
- **1d — Настройки**
- **2e — Дневная тема**: тоже тёмная (светло-серую 1e–1h НЕ реализовывать).
- **1i / 1j** — токены и крупные планы компонентов с размерами.

## Жёсткие технические требования
- Экран 1280×720, landscape, тач без энкодера. Fullscreen immersive, safe-зон нет.
- Просмотр с 70–90 см, в движении, при вибрации. Минимальная тач-цель **64 dp**, минимальный кегль **14 dp**.
- Никакого глянца/стекла/бликов. Матовые поверхности.
- Число плиток карусели **переменное** (6–12): позиция плитки = f(offset от фокуса), виртуализация, индикатор-полоски масштабируются на любое N.

```kotlin
    val callGreen     = Color(0xFF1E7A3C)  // только кнопка «Позвонить»
}
```

### Цвета — день (тоже тёмная, экран 2e)
```kotlin
object DayColors {
    val bgBase        = Color(0xFF1C1F24)  // чуть светлее ночи
    val surface       = Color(0xFF272C32)
    val surfaceHi     = Color(0xFF2E343B)
    val textPrimary   = Color(0xFFEDEFF2)  // контраст ~12:1 против солнца
    val textSecondary = Color(0xFFA6ADB5)

```
День отличается от ночи: выше контраст, ярче янтарь, **ambient-свечение и glow-тени отключены** (солнце их «съедает»).

### Типографика
Шрифт: **Archivo** (Google Fonts, SIL OFL — можно вшивать). Цифры везде `FontFeature "tnum"` (tabular).
```kotlin
display  = 31.dp semibold   // название трека
clock    = 29.dp semibold   // часы в статус-ленте
title    = 20.dp semibold   // заголовок фокусной плитки
body     = 17.dp regular    // дата, строки списков (в макете 18.7dp/28px для строк настроек)
label    = 16.dp regular    // кнопки, подписи
caption  = 14.dp regular    // вторичные подписи — МИНИМУМ
```

### Отступы / радиусы
```
space: 4 / 8 / 16 / 24 / 32; screen.padding = 43dp (боковые поля экрана)
radius: s 8 / m 11 (плитки приложений 16dp в макете=24px... см. ниже) / l 16–19 (карусель) / pill 999
Фактические радиусы: плитка карусели 19dp, плитка приложений 16dp, клавиша набора 13dp, карточки 16dp
```

### Состояния (обязательно — заказчик жаловался «не видно, что нажалось»)
Pressed = тройной сигнал, всегда:
- `scale 0.97` (вход 90 ms easeOut, выход 220 ms spring(0.6, 500))
- рамка `accentAmber` (границы 1→2 dp)
- фон осветляется surface → surfaceHi
Focused (центр карусели): рамка amber 2dp + glow `0 0 43dp amber 22%` (ночь) / без glow, рамка 2.5dp (день).
Disabled: `alpha 0.45`.

### Motion
```
carousel.snap     spring(dampingRatio = 0.82, stiffness = 380)
carousel.fling    decay + snap к ближайшей плитке
press.in          90 ms, scale → 0.97
press.out         220 ms, spring(0.6, 500)
ambient.breathe   4200 ms easeInOutSine, бесконечно, alpha 0.28↔0.42
screen.transition 260 ms, fade + slide 24 dp, FastOutSlowIn
vinyl.spin        1800 ms/оборот, linear, только при isPlaying
vinyl.slideOut    пластинка выдвигается из конверта при play (~400 ms, тот же spring)
like.toggle       scale 0.8 → 1.1 → 1, 320 ms spring
```

### Ambient-свечение (только ночь, экран Home)
Не bitmap — параметры: `Brush.radialGradient`, эллипс ~600×187 dp, центр на 93 dp ЗА нижней кромкой, цвет amber, blur 20 dp, alpha анимируется 0.28–0.42 (`rememberInfiniteTransition`).

## Screens / Views

### 1. Home (2a)
- **Статус-лента** 59 dp: часы 29dp semibold · разделитель 1px hairline · дата по-русски 17dp secondary · температура 17dp medium · справа эмблема 29dp + «X5» 16dp letterSpacing 0.14em. Под лентой янтарная линия 2px: `linear-gradient(90deg, amber 70% → amber 8%)`.
- **Карусель** (центр экрана, perspective 1500px/1000dp):
  - Фокусная плитка: **207×207 dp**, surfaceHi, рамка amber 2dp, radius 19dp, glow. Иконка **88 dp** stroke 1.6 amber, подпись 17dp `textSecondary` (иконка главная, текст вторичен!).
  - Соседние: 160dp, rotY ±26°, alpha 0.55, иконка 69dp; далее 140dp / ±38° / 0.32 / 57dp; далее 127dp / ±48° / 0.16 / 51dp. Шаг между центрами ~179dp.
  - Свайп с инерцией + snap; тап по боковой = прокрутка к ней; тап по фокусной = открыть.
- **Индикатор**: полоски 11×3 dp (активная 21dp, amber), количество = числу плиток.
- Плитки: Музыка, Навигация, Телефон, Bluetooth, Борткомпьютер, Приложения, Настройки, Радио… (список динамический).

### 2. Музыка (3a — финал)
- Верх: кнопка «назад» — только шеврон, тач-цель 64×43dp, БЕЗ подписи «Музыка». Справа часы + температура.
- **Конверт** 287×287 dp, radius 5dp, слева тёмный корешок 9dp (`black 28%`). Внутри обложка альбома (из MediaSession / API Яндекс Музыки).
- **Пластинка** Ø269 dp за конвертом, выезжает вправо при play (в покое видна на ~30%, при play — так, чтобы **лейбл был виден целиком**): канавки `repeating-radial-gradient` (#16181C/#212429, шаг ~1.7dp), лёгкий конический блик, лейбл Ø85dp amber с внутренним кругом #F2EFE9, отверстие 11dp bgBase. Вращение при play.
- Слева за кадр выглядывает предыдущий конверт (alpha 0.5) — свайп по конверту = prev/next.
- Под конвертом: точка amber 7dp + «Яндекс Музыка · Моя волна» 15dp secondary.
- Правая колонка (x ≈ 557dp): трек 32dp semibold ellipsize, исполнитель 20dp secondary; **прогресс**: тач-зона 64dp во всю ширину (тап и драг = seek), трек-линия 5dp `white 12%`, заливка amber, кноб 19dp #E4E7EA + halo 3dp amber 28%; тайминги 15dp tabular по краям.
- **Транспорт**: prev/next 64dp круг `white 4%`, play/pause **85dp** surfaceHi + кольцо amber 2dp + glow. Иконки заливкой.
- Ряд ниже: «В любимом» (лайк: on = заливка amber + фон amber 10% + рамка amber 50%; off = контурное сердце, нейтральная рамка) и «Плейлисты» — pill-кнопки высотой 51dp.

### 3. Телефон (2c)
Открывается с плитки «Телефон». Слева (ширина ~347dp): строка набора 35dp medium tabular с нижней линией 2px + backspace 64dp; недавние 3 строки по 61dp (имя 17dp, время 15dp tertiary, разделители hairline); кнопка **«Позвонить»** 69dp высотой, pill, `callGreen`, иконка+текст 20dp semibold. Справа: клавиатура 3×4, клавиши **~123×71 dp**, radius 13dp, surface, цифра 27dp medium, кириллические буквы 9dp tertiary letterSpacing 0.22em. Pressed — стандартный тройной сигнал.
В шапке: имя подключённого телефона с BT-иконкой.

### 4. Bluetooth (2d)
Тумблер вкл/выкл в шапке (64×35dp). Слева список (ширина ~467dp): подключённое устройство — карточка 77dp, фон amber 6%, рамка amber 35%, статус «Подключено · музыка + звонки» amber, заряд справа; сопряжённые — строки 72dp, статус tertiary, действие «Подключить» 16dp. Справа (ширина ~267dp): кнопка **«Новое устройство»** 120dp — пунктирная рамка amber 45%, иконка «+» в круге 48dp; карточка «Видимость»: система видна как «BMW X5», PIN-код и таймер видимости (mono 12dp).
Пейринг: при сопряжении показывать код подтверждения крупно (модально).

### 5. Приложения (1c)
Сетка 4×2, плитки **~197×172 dp**, radius 16dp, surface: контейнер иконки 61dp radius 16dp surfaceHi + название 16dp. Иконки приложений — системные (PackageManager). Последняя плитка — **«Перезагрузка»**: пунктирная рамка amber 35%, иконка power amber (reboot через su / API устройства).

### 6. Настройки (1d)
Список строк 79dp, разделители hairline, заголовок 19dp primary + подпись 14dp tertiary:
1. «Автозапуск Борткомпьютера» — тумблер 64×35dp (трек amber, кноб 28dp).
2. «Тема оформления» — сегмент-контрол День/Ночь/Авто (сегмент 39dp высотой, активный: текст amber, фон amber 14%, рамка amber 50%). Авто = по датчику освещённости / времени.
3. «Приложения по умолчанию» — строка с шевроном (музыка, навигация).
4. «Версия лаунчера» — версия+сборка, кнопка «Проверить обновление» pill 43dp, рамка amber.

## Interactions & Behavior — сводка
- Карусель: drag/fling с инерцией, snap; позиция сохраняется между запусками.
- Все нажатия — тройной pressed-сигнал (см. States) + haptic, если устройство умеет.
- Прогресс-бар: тап = мгновенный seek, драг = scrub; snap к 5 c не нужен на релизе — по вкусу.
- Пластинка: slideOut + spin при play, задвигается при pause.
- Назад отовсюду — шеврон слева в шапке (64dp цель) + системный back.
- Темы: ночь/день/авто; день = отдельная палитра DayColors, НЕ инверсия и НЕ светлая.

## State Management
- `launcherState`: список плиток (динамический, из настроек), индекс фокуса.
- `mediaState`: через MediaSessionManager / NotificationListener от Яндекс Музыки: track, artist, artwork, position, duration, isPlaying, isLiked. Лайк — через media action, если доступен.
- `phoneState`: HFP-профиль BT (набор, недавние, звонок).
- `btState`: список сопряжённых/подключённых, режим видимости, PIN.
- `settingsState`: DataStore — автозапуск, тема, дефолтные приложения.

## Assets
- Иконки — простые line-иконки stroke 1.6, скруглённые концы (в HTML вшиты как SVG — можно перенести в `ImageVector` 1:1).
- Эмблема в статус-ленте — **нейтральная квадрантная** (conic: amber/graphite). Роундель BMW — товарный знак, в макет не включён; владелец подставит свою графику 29dp.
- Обложки альбомов — из media-сессии, в макете полосатые плейсхолдеры.
- Ambient-свечение — только параметры градиента (см. Tokens), не картинка.
- Шрифты: Archivo (400/500/600/700), для служебных подписей JetBrains Mono — в прод не обязателен.
