# BMW iDrive Launcher

[English](README.md) · **Русский**

**Кастомный Android-лаунчер (домашний экран), превращающий дешёвую китайскую магнитолу в премиальный интерфейс в стиле BMW iDrive.**

Сделан для **BMW X5 (E53) 2005 года** с головным устройством **XTRONS** на Android. Заменяет тормозной заводской рабочий стол быстрым тач-интерфейсом в духе современного **iDrive**: 3D-карусель плиток, янтарь приборной подсветки на почти-чёрном графите, экран «сейчас играет» для **Яндекс Музыки**, гарантированный автозапуск приложения **i-Bus** (борткомпьютер), обновления «по воздуху» (OTA) и перезагрузка в один тап — всё на **Kotlin + Jetpack Compose**, покрыто скриншот-тестами, **без root**.

## Зачем

Заводской лаунчер на этих XTRONS-головах (заброшенный сторонний «iDrive Launcher») тормозит, не поддерживается и не делает надёжно две главные для ретрофита E53 вещи:

1. **Автозапуск i-Bus** при включении — чтобы борткомпьютер и интеграция с машиной поднимались сами (i-Bus общается с авто через USB→I-Bus адаптер Resler).
2. **Не мешать** — быстрый, читаемый с одного взгляда домашний экран, которым удобно пользоваться на ходу с расстояния 70–90 см.

Этот проект — написанная с нуля замена: своё, поддерживаемое, ощущается как настоящий BMW.

**Цели дизайна**

- **Быстро и отзывчиво** — без лагов на слабом Qualcomm.
- **Тач-центрично** — у E53 нет шайбы-контроллера, только тачскрин XTRONS.
- **Язык поверхностей BMW** — янтарь приборки на графите, объём в духе iDrive.
- **Железобетонный автозапуск i-Bus** + кнопка **перезагрузки** + **самообновление**, чтобы улучшать без флешки.

## Возможности

### Главный экран — крутящаяся 3D-карусель плиток
- **Бесконечно зацикленная цилиндрическая 3D-карусель** крупных плиток (в стиле iDrive-2016): центральная плитка плоская, в фокусе, с янтарной рамкой и свечением; боковые уходят в перспективу, уменьшаются и тускнеют.
- **Иконка-доминанта** на заполненных графитовых плитках; тап по всей плитке.
- Весь 3D-«характер» задаёт чистый, покрытый юнит-тестами `CarouselGeometry` (поворот / масштаб / прозрачность по позиции) — его можно тюнить и раскатывать по воздуху без правки Compose.
- **Статус-лента** (часы · полная дата · температура · нейтральная эмблема в стиле BMW · «X5») и «дышащее» **янтарное свечение**.
- **Полоски-индикатор**, масштабирующиеся под любое число плиток.

### Музыка — «сейчас играет» из Яндекс Музыки (экран плеера v4)
- Управляет **Яндекс Музыкой** через штатный Android `MediaSession` / `MediaController` (без реверс-инжиниринга), используя `NotificationListenerService`.
- **Экран плеера v4:** **обложка альбома на весь фон** (скрим + виньетка для читаемости); **пройденная часть прогресса — живой янтарный эквалайзер** (полоски анимируются при игре, замирают на паузе). Ряд управления — *перемешать · пред · плей/пауза · след · лайк*, перемотка тапом и перетаскиванием.
- **Надёжный холодный старт:** открытие Музыки само будит Яндекс; если убитое приложение не заводится в фоне — явная кнопка **«Включить музыку»** запускает его на переднем плане, стартует «Моя волна», и возвращает на экран «сейчас играет».

### YouTube — за per-app VPN
- Плитка **YouTube**, открывающая приложение. YouTube в РФ режется, поэтому идёт через **VPN с обходом DPI** (VLESS + Reality на [sing-box](https://sing-box.sagernet.org/)) в режиме **постоянного _per-app_ `VpnService`** — через туннель уходит только трафик YouTube, всё остальное (Яндекс, навигация) напрямую. Без root в рантайме. Дизайн: [`youtube-vpn-design.md`](docs/superpowers/specs/2026-07-06-youtube-vpn-design.md).

### Автозапуск борткомпьютера (i-Bus) — киллер-фича
- При включении лаунчер **сам запускает i-Bus** (тот цепляется к машине), затем возвращает себя на передний план — с подавленными анимациями, чтобы i-Bus не мелькал на экране.
- Полностью **без root** (запуск как foreground-HOME + переупорядочивание задач), с устойчивым к повторам автоматом состояний «один раз на процесс».

### Ящик приложений
- Сетка установленных приложений (реальные иконки из `PackageManager`) плюс отдельная, вынесенная в угол плитка **Перезагрузка** (тап-подтверждение).

### Настройки
- Тумблеры **автозапуска i-Bus** и **вывода на передний план**, сегмент-контрол темы **День / Ночь / Авто**, строка **приложений по умолчанию**, действие **«Сделать лаунчером по умолчанию»** и **встроенный апдейтер**.

### Перезагрузка без root
- Перезагружает эту прошивку Microntek/HCT вендорным бродкастом (`com.microntek.hctreboot`) — подтверждённо работает из непривилегированного приложения, без `su`.

### Самообновление по воздуху
- Проверяет JSON-манифест и ставит новые сборки либо тихо (если вдруг есть root), либо через системный установщик (без root) — см. [OTA](#обновления-по-воздуху-ota).

| **Прошивка** | Microntek / HCT, **Android 13** |

## Как включить ADB на таких головах — пароль `adbon`

Главная засада при разработке под такие головы: обычный трюк *«тапни Номер сборки 7 раз»* **не работает**, а пункт *«Для разработчиков»* не появляется — экран «О системе» показывает лишь версию MCU вида **`if2 - V2`**. Недокументированное решение: зайти в **Заводские настройки** и ввести пароль **`adbon`** — он разблокирует «Для разработчиков» / ADB. Дальше **Отладка по Wi-Fi** работает без USB-кабеля, а так как прошивка — сборка `userdebug`, **работает `adb root`**.

На реверс-инжиниринг ушёл целый вечер, поэтому оформлено отдельным гайдом для всех, у кого голова **XTRONS / Microntek / HCT / MTCE**:

📄 **[Включение ADB / «Для разработчиков» на китайских Android-головах (`adbon`)](docs/ENABLING-ADB-HCT-HEADUNITS.md)**

## Дизайн-система

Визуальный язык — выверенная «ночная» автомобильная тема: **аутентичный янтарь приборной подсветки BMW `#FF7E00`**, дозированно поверх почти-чёрного графита, матово (никакого глянца/стекла — блики в машине убивают всё).

**Токены цвета (ночь)**

| Токен | Значение | Назначение |
|---|---|---|
| `bgBase` | `#0A0B0D` | фон экрана |
| `surface` | `#15181B` | заливка плитки |
| `surfaceHi` | `#1E2226` | нажатая / фокусная заливка |
| `textPrimary` | `#C7CCD2` | основной текст (не чисто белый — блики) |
| `textSecondary` | `#8A9199` | вторичный текст |
| `accentAmber` | `#FF7E00` | единственный акцент |

- **Типографика:** **Inter** (400/500/600/700), табличные цифры. *(В дизайн-хендоффе был Archivo, но у Archivo нет кириллицы — интерфейс русский — поэтому взят Inter.)*
- **Взаимодействие:** каждое нажатие даёт «тройной сигнал» — уменьшение масштаба + янтарная рамка + подсветка фона — плюс вибро, потому что на экране в машине нажатие надо **видеть и чувствовать**.
- **Движение:** пружинный snap карусели, «дышащее» свечение, никакой лишней анимации.

Дизайн-референсы (рендеры макетов + полный спек токенов) — в [`docs/mockups/`](docs/mockups/).

## Архитектура

Чистый **Kotlin + Jetpack Compose**, без DI-фреймворка, компактно и читаемо. Логика, которую *можно* сделать чистой и покрыть юнит-тестами, *сделана* такой (геометрия, форматирование времени, маппинг воспроизведения, разрешение темы); Compose-UI проверяется скриншот-goldenами.

```
HomeActivity (единая Compose-Activity, объявлена как HOME)
 ├─ NavHost: home · music · apps · settings
 ├─ SettingsStore (DataStore)         — сохранённые настройки
 ├─ AutostartController               — автомат автозапуска i-Bus (без root)
 ├─ AppLauncher / InstalledApps       — запуск + перечисление приложений
 ├─ RootShell / ShellCommands         — root-адаптивно (работает и без root)
 ├─ update/ (UpdateChecker, ApkDownloader, ApkInstaller, RootDetector)
 └─ music/ (MediaSessionRepository, MusicController, MusicViewModel,
            MediaNotificationListener, PlaybackMapper, NowPlaying)
ui/
 ├─ home/   CarouselGeometry · HomeCarousel · TileCard · StatusRibbon ·
 │          RibbonClock · RoundelIcon · AmbientGlow · PageIndicator
 ├─ apps/   AppsScreen
 ├─ settings/ SettingsScreen
 └─ theme/  Color · Theme · Type · Pressable · ScreenHeader
```

**Принципы**

- Тюнинг-константы (углы карусели, размеры, свечение) живут в чистых объектах — «характер» настраивается и раскатывается по OSA без правки вьюх.
- Всё деградирует мягко: без root и без сети.
- Лаунчер — это HOME-приложение: он **не имеет права падать**; все внешние интенты защищены.

## Сборка и запуск

**Нужно:** JDK 17, Android SDK (compileSdk 34), Gradle (wrapper в комплекте).

```bash
export JAVA_HOME=/путь/к/jdk-17
export ANDROID_SDK_ROOT=/путь/к/android-sdk

# debug APK
./gradlew :app:assembleDebug

# юнит-тесты + проверка скриншотов
./gradlew :app:testDebugUnitTest :app:verifyPaparazziDebug
```

- `applicationId` = `online.k73.bmwlauncher` · `minSdk` 26 · `targetSdk` 33 · `compileSdk` 34.
- **Подпись релиза** читается из `keystore.properties` (в gitignore) — создайте свой keystore; из коробки собирается debug без подписи.

Установка на голову через ADB (или встроенным апдейтером):

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Затем назначьте приложением «Главный экран» по умолчанию (Настройки Android → Приложения по умолчанию → Приложение «Главный экран»).

## Тесты

- **Юнит-тесты** (JUnit4 + Robolectric) покрывают чистую логику: геометрию карусели, форматирование часов/даты, маппинг воспроизведения, разрешение темы, проверку обновлений и автомат автозапуска.
- **Скриншот-тесты** ([Paparazzi](https://github.com/cashapp/paparazzi)) рендерят каждый экран в 1280×720 головы и сравнивают с зафиксированными goldenами — визуальная регрессия валит CI. Эти же goldenы служат скриншотами в README.

```bash
./gradlew :app:recordPaparazziDebug   # перегенерировать goldenы
./gradlew :app:verifyPaparazziDebug   # проверить против goldenов
```

## Обновления по воздуху (OTA)

Приложение обновляет себя само, чтобы улучшения приезжали без флешки:

1. **Настройки → Обновление → «Проверить»** тянет JSON-манифест (`latest.json`) с описанием свежей сборки.
2. Если новее — кнопка становится **«Обновить»** и ставит её:
   - **с root** (если вдруг есть): тихо `pm install -r` + перезапуск,
   - **без root** (обычный случай): загрузка + интент системного установщика через `FileProvider`.

`scripts/release.sh` собирает подписанный релиз, заливает APK и пишет манифест. (Цель заливки специфична для окружения — направьте на свой хост.)

## Известные ограничения

- **Без root — намеренно.** То, что рутованный лаунчер мог бы делать (полностью тихие установки, принудительный HOME), делается вежливо, с подтверждением пользователя.
- LCD головы «поднимает» почти-чёрный к подсвеченному сине-серому — полностью тёмные экраны на фото выглядят синее, чем рендерятся.
- Интеграция с Яндекс Музыкой ограничена тем, что отдаёт её `MediaSession` (транспорт и «сейчас играет» гарантированы; просмотр библиотеки — нет).
- **Нет _постоянного_ root на устройстве.** В прошивке нет `su`/Magisk (и нет доступного USB для `fastboot`), поэтому ADB-root есть только при живом подключении — см. [гайд про `adbon`](docs/ENABLING-ADB-HCT-HEADUNITS.md). Поэтому VPN для YouTube сделан на постоянном `VpnService`, а не на root-туннеле.
